Features
Built like infrastructure, not a hack.

Every piece is designed to run unattended for days on a phone in your pocket.

⚡

Zero-config OpenAI surface

Drop-in compatible with anything that speaks /v1/chat/completions — Hermes Agent, LangChain, curl, your own app.

◈

Hot-loaded site config

Selectors and JS live on disk. Edit a file and the next request uses it — no rebuild, no app restart, safe fallbacks.

▣

Headless WebView core

A real Chromium session does the work — login, cookies, streaming, reasoning traces, all handled natively.

⛭

Adaptive rate limiting

Randomised delay ranges, session warmup, and burst penalties that mimic human rhythm instead of a fixed interval.

🛡

Account-safe by design

Desktop user-agent, human-like typing, and throttling that never triggers a hard block on a live working session.

▤

Response hygiene

UI chrome, leaked tool-call JSON, and pagination junk are stripped before the reply leaves — history stays clean.

Anti-detection
Engineered to look like a person.

A scraper is fingerprinted by its rhythm. This bridge is built so that no two requests look alike.

  • ✓
    Randomised request delay

    Every call waits a different amount inside the configured range. Machine-precise regularity is the single easiest behaviour to detect.

  • ✓
    Session warmup

    The first requests in a fresh session run slower — a person reads the page before they settle into a pace.

  • ✓
    Burst protection

    Consecutive rapid calls earn an escalating, capped penalty instead of tripping a block.

  • ✓
    Desktop identity

    Mobile WebView signature is replaced with a desktop Chrome user-agent and matching navigator profile.

  • ✓
    Human-like input

    Prompts are entered as value-set plus real input events, never a raw clipboard paste.

  • ✓
    No hard caps

    Throttling only — the bridge never emits a 429 that would kill a live, working session mid-task.

Quick start
Running in under a minute.
1 · install apk → sign in once → service starts automatically
# the bridge exposes a stable key at
cat ~/.wv_api_key   # → export WV_KEY=...

# any OpenAI client works now
curl http://127.0.0.1:8080/v1/chat/completions \
  -H "Authorization: Bearer $WV_KEY" \
  -d '{"model":"deepseek-webview","messages":[{"role":"user","content":"hello"}]}'
2 · tune live web api/deepseek/bridge.properties
# edit on disk — the next request uses it
requestDelayMinMs   = 3000
requestDelayMaxMs   = 6000
sessionWarmupDelayMs= 7000
pageStallSeconds    = 25
timeoutSeconds      = 300

# delete a file → compiled default returns
# the app never breaks from this directory
